# App del Clima

Aplicación web desarrollada con HTML, CSS y JavaScript puro.
Consulta el clima actual usando la API libre de Open-Meteo.

## Tecnologías
- HTML
- CSS (BEM)
- JavaScript (Vanilla)
- Open-Meteo API

## Funcionalidades
- Búsqueda por ciudad
- Clima actual
- Manejo básico de errores
